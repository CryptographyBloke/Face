# v0.4 browser screenshots

These are captured from the real application and public API. The responsive QA iframe runs
at 1440, 1024, 768 and 375 CSS pixels. The 1440 frame is displayed at 85% within the browser;
other frames are unscaled. Screenshots include the QA controls and surrounding browser canvas.
Each checked frame had matching document clientWidth/scrollWidth (no horizontal overflow).
These captures precede the curated Aave ID correction from aave.eth to aavedao.eth;
the production site uses the live verified Space ID.
