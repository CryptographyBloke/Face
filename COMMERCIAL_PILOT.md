# First two DAO design partners

Offer a narrowly scoped pilot, not an unbuilt enterprise subscription:

1. Import one real Snapshot Space and review the bounded public governance directory together.
2. Let a few consenting wallet holders create signed native public profiles on a persistent
   pilot server. Explain that claiming a profile is not admission to the DAO.
3. Let a current EOA Snapshot admin sign branding, role labels and revocable organization badges.
4. Embed the SDK avatar component in one partner-controlled directory or governance view.
5. Record actual resolver latency, failure/retry rates, source correctness and repeat usage.

Read-only Vercel previews demonstrate steps 1 and 4. Signed records/admin writes currently
require the persistent Node + SQLite application; they are not live on the production domain.
The three `examples/` integrations are first-party demos, not customers or partnerships.

Potential paid work: a reviewed managed deployment, partner branding, an integration package
and ongoing reliability/support. Prices and service commitments should be agreed only after
one organization repeatedly uses the workflow. Billing, revenue, adoption and SLAs are not
claimed by this repository.

Not yet delivered: invitation onboarding, CSV/bulk exports, WalletConnect/mobile-wallet
coverage, Safe/EIP-1271 administration, a shared serverless database, complete historical
indexing, append-only audits, legal policies tailored to a jurisdiction, or a production SLA.

Next most valuable step: one real partner-owned integration and a durable staging backend
with backup/restore verification. That is more useful than adding token/NFT mechanics.
